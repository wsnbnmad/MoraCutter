# Mora Cutter MVP

音MAD・YTPMV向けの、人力ボーカロイド用音声切り出し支援ツールです。音声はすべてローカルで処理します。

## 高精度な境界検出（任意）

`MFA Japanese v3.0.0` と `Kotoba-Whisper v2.2 → ReazonSpeech CTC → Silero VAD` は、通常版とは別の任意依存です。開発版で使う場合は一度だけ次を実行します。

```powershell
python -m pip install -r requirements-high-accuracy.txt
```

Windowsでは [setup_high_accuracy.bat](setup_high_accuracy.bat) をダブルクリックしても同じ準備ができます。

RTX 3060などのNVIDIA GPUで高速化するには、続けて [setup_gpu_acceleration.bat](setup_gpu_acceleration.bat) を実行します。これはCUDA対応PyTorchへ切り替えるための一度だけの準備です。

MFAは素材テキスト必須です。Windows版MFAはKalpyを含むConda環境が必要なため、[setup_mfa.bat](setup_mfa.bat) で専用環境を用意します。Kotoba経路では、素材テキストがある場合に歌詞全体をReazonSpeech CTCへ強制アラインし、各モーラを実際の音声フレームへ割り当てます。ダウンロード済みモデルは `models_cache` に置かれ、Gitと配布ZIPには含めません。

## ベンチマーク

`D:/曲/zunda/zunda/untitled.wav` と同梱の歌詞を固定ベンチマークとして登録しています。`python benchmarks/run_untitled_benchmark.py baseline` で基本の回帰検証、`kotoba` または `mfa` を指定して高精度経路を検証します。

## 起動

Python 3.10以上、NumPy、FFmpeg / FFplayが必要です。

Windows:

```powershell
python -m pip install numpy
python main.py
```

Windows向けの再現可能ビルドと正式署名については `CODE_SIGNING.md` を参照してください。

macOS / Linux:

```bash
python3 -m pip install numpy
python3 main.py
```

FFmpegとFFplayはPATHから見つかる必要があります。アプリ起動後、`ヘルプ > 動作環境を確認`でも確認できます。

## 基本操作

1. `ファイル > 音声を追加`で複数ファイルを読み込みます。
2. 波形上を右ドラッグして範囲を選びます。範囲選択だけでは候補は作られません。
3. `F` または「フリックパッドを表示 (F)」を押して発音を選び、`S` / `C` / `E` と再生ヘッドで開始・cue・終了を調整します。
4. テキストがある場合は右下へ入力し、`自動候補検出`を押します。
5. 候補を確認後、`書き出し`から個別WAVへ出力します。

黄色が区間開始、オレンジがcue、水色が終了です。左クリック／左ドラッグは赤い再生ヘッドを移動します。候補の開始・cue・終了は、再生ヘッド位置で `S` / `C` / `E` を押して調整できます。

右ドラッグで範囲を選択します。表示位置の左右ボタンは100ms単位で移動します。

## 外部モデル

`models/<モデル名>/model.json` を作ると検出モデル一覧へ追加されます。

```json
{
  "name": "My aligner",
  "command": ["python", "detect.py"],
  "supports_gpu": true
}
```

アプリは標準入力へ1行のJSONを渡し、標準出力から1行のJSONを受け取ります。

入力例:

```json
{"audio_path":"voice.wav","transcript":"こんにちは","unit":"mora","use_gpu":true}
```

出力例:

```json
{"segments":[{"start":0.1,"cue":0.14,"end":0.3,"label":"こ","confidence":0.94}]}
```

## 初版の制限

内蔵ベースラインは音響的な発音認識モデルではありません。テキストをモーラに分解し、発声区間内の音量変化から境界を推定します。テキストなしでは発音名を判定できないため「未分類」になります。発音認識にはWhisper smallまたはlarge-v3を選択してください。Whisperのモーラ境界も音量の谷で細分化するため、促音、無声化、早口、歌唱、子音のみの境界では手直しが必要です。
